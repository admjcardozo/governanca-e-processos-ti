# Documentação de Referência

Esta pasta reúne os documentos complementares necessários para compreender e consultar o programa integrado SGS / SGSI.

## Conteúdo previsto

- Glossário de termos, siglas e conceitos.
- Premissas e limites do projeto.
- Referências metodológicas e normativas.
- Critérios de interpretação dos documentos.
- Histórico de versões e alterações relevantes.

## Referenciais considerados

- ISO/IEC 38500 — Governança de TI.
- ISO/IEC 20000-1 — Gestão de serviços.
- ISO/IEC 27001 — Gestão da segurança da informação.
- COBIT — Governança e gestão de TI.
- ITIL 4 — Gestão de serviços de TI.
- ISO 31000 — Gestão de riscos.
- ISO 22301 — Gestão de continuidade de negócios.
- LGPD — Lei Geral de Proteção de Dados Pessoais.
- COSO — Referencial para controles internos e gestão de riscos.

A inclusão de um referencial não significa certificação, conformidade integral ou implementação formal.

## Natureza do projeto

Este é um projeto autoral e conceitual. A aplicação dos referenciais deve considerar o contexto, os requisitos aplicáveis e a avaliação de cada organização.
