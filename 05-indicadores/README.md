# Indicadores de Desempenho e Metas

Esta pasta reúne a estrutura de indicadores para acompanhar o desempenho dos processos e serviços de TI do programa SGS / SGSI.

## Conteúdo previsto

- Indicadores operacionais e gerenciais.
- Definições, fórmulas e critérios de cálculo.
- Fontes de dados e periodicidade de apuração.
- Metas e limites de desempenho propostos.
- Responsáveis pelo acompanhamento.
- Formato de apresentação dos resultados.
- Critérios para análise de desvios e planos de melhoria.

## Premissas

Os indicadores e as metas deverão ser definidos conforme os objetivos, os riscos, a capacidade operacional e as necessidades de cada organização.

Este projeto é autoral e conceitual. Eventuais metas, valores e resultados demonstrativos são simulados e não representam resultados reais de uma implantação empresarial.
