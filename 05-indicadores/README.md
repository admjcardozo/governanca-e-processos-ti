# Indicadores e Acompanhamento de Desempenho — SGS/SGSI

Esta pasta reúne os materiais de referência para definição, organização e acompanhamento de indicadores de desempenho do Programa Integrado de Governança, Serviços e Segurança de TI (SGS/SGSI).

O objetivo é apoiar a análise dos serviços, dos processos, dos riscos, dos controles e das iniciativas de melhoria contínua, fornecendo uma base conceitual para acompanhamento e tomada de decisão.

## Critérios de utilização

Antes da aplicação operacional, cada indicador deve ter sua definição, fórmula, fonte de dados, periodicidade, responsabilidades e critérios de avaliação validados.

Metas e resultados somente devem ser apresentados como reais quando formalmente definidos ou sustentados por dados verificáveis. Valores ilustrativos devem ser identificados explicitamente como simulados.

## Natureza do projeto

Este material integra um projeto autoral e conceitual para portfólio profissional. Os indicadores e métodos apresentados são propostas de referência, não evidências de medição, implantação, desempenho real, auditoria ou certificação de uma organização.
